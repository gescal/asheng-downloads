## ASheng 外掛版本管理（免費）

到右側 **Releases** 下載最新版的 `.dmg`：

1. 雙擊下載的 `.dmg`，會出現安裝視窗。
2. 把左邊的「AShengPluginManager」拖到右邊的「應用程式」資料夾。
3. 從「應用程式」打開（第一次 macOS 詢問時按「打開」），之後也可以用 Spotlight 搜尋「ASheng」。

每個版本的 SHA-256 都列在 Release 說明裡，也可以和下載頁上的數字核對。

系統需求：Apple Silicon Mac · macOS 14 以上
